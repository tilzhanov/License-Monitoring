## Decisions Made

- **Dynamic h1 for 404 (Option 1):** The `{{ title if title else "Страница не найдена" }}` pattern resolves the test_licenses.py:215 conflict without modifying `app/routers/licenses.py`. When the router passes `title="Лицензия не найдена"`, that string renders in the h1. Generic 404s show the spec default.
- **{{ submit_text }} kept:** The primary form button uses the route-provided `submit_text` context variable rather than hardcoding. No test asserts on button text, and the route already provides appropriate copy.
- **Slash separator in breadcrumb:** Replaced `&gt;` entity with `/` span and added arrow-left icon as leading affordance per UI-SPEC Component 10.
