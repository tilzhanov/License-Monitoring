Create `app/services/telegram.py` with these functions:

1. `send_telegram_message(token: str, chat_id: str, text: str) -> dict`:
   - Build URL: `f"https://api.telegram.org/bot{token}/sendMessage"`
   - Payload: `{"chat_id": chat_id, "text": text}` — no parse_mode per D-03 (plain text).
   - Use sync `httpx.Client(timeout=10.0)` as context manager per project convention (sync routes).
   - On success (`data.get("ok")` is True): return `{"ok": True}`.
   - On API error: return `{"ok": False, "error": description, "error_code": code}`.
     - Map error codes to Russian messages: 401="Неверный токен бота", 400="Некорректный запрос (проверьте chat_id)", 403="Бот заблокирован или не добавлен в чат", 429="Слишком много запросов, попробуйте позже".
   - On `httpx.TimeoutException`: return `{"ok": False, "error": "Тайм-аут соединения с Telegram", "error_code": 0}`.
   - On `httpx.HTTPError`: return `{"ok": False, "error": f"Ошибка HTTP: {exc}", "error_code": 0}`.
   - NEVER log the full URL (contains token) per Pitfall 3.

2. `format_license_line(enriched_item: dict) -> str`:
   - Extract `lic = enriched_item["license"]`, `days = enriched_item["days_remaining"]`.
   - Format date as `lic.expiry_date.strftime("%d.%m.%Y")`.
   - Build line: `f"* {html.escape(lic.product_name)} \u2014 {date_str} ({days} \u0434\u043d.) \u2014 {html.escape(lic.responsible)}"` per D-03.
   - If `lic.responsible` is None or empty, omit the trailing ` \u2014 {responsible}` part per D-03.
   - Use `html.escape()` on product_name and responsible per coding convention (even for plain text, future-proofing).

3. `format_digest(enriched_licenses: list) -> str | None`:
   - Filter: `expired = [e for e in enriched_licenses if e["status"] == "expired"]`
   - Filter: `warning = [e for e in enriched_licenses if e["status"] == "warning"]`
   - Per D-02: only expired and warning are included (active excluded).
   - Per D-04: if both lists empty, return `None` (send nothing).
   - Build lines list:
     - If expired: append `"\U0001f534 \u0418\u0441\u0442\u0435\u043a\u043b\u043e"` header, then `format_license_line(e)` for each.
     - If warning: append `"\U0001f7e1 \u0418\u0441\u0442\u0435\u043a\u0430\u0435\u0442 \u0441\u043a\u043e\u0440\u043e"` header, then `format_license_line(e)` for each.
   - Per D-01: emoji headers with two sections.
   - Return `"\n".join(lines)`.

Import: `import html`, `import httpx`.
