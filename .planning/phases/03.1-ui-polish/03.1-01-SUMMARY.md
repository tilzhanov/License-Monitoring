## Decisions Made

- **Inline SVG sprite over per-icon files:** Single HTTP payload, `currentColor` inheritance, no JS dependency, simpler caching.
- **box-shadow inset for status row bar:** A `<tr>` cannot host `::before`; box-shadow works universally and respects row height.
- **12px removed from spacing scale:** UI-SPEC enforces strict 8-point grid — no `--space-3`.
- **Smoke tests as file-greps:** Avoid TestClient dependency for visual/structural assertions. <1s run, decoupled from DB/Jinja rendering, catches foundation drift.
- **Brand text preserved:** `test_health.py:69` asserts `"License Monitor" in response.text` — kept literal to avoid a Phase 1 regression.
