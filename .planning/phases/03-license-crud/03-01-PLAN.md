    **Create `app/routers/licenses.py`** with these endpoints:

    1. `GET /licenses/new` — renders `license_form.html` in "add" mode.
       - `sync def new_license(request: Request):`
       - Pass context: `{"mode": "add", "title": "Новая лицензия", "action_url": "/licenses", "submit_text": "Добавить лицензию", "license": None, "errors": {}}`

    2. `POST /licenses` — creates a new license from form data (per D-01, LIC-01).
       - `sync def create_license(request: Request, db: SessionDep):`
       - Parse form fields using `await request.form()` — EXCEPTION to sync rule: use `async def` for this endpoint because `request.form()` is async. Alternatively, use `Form(...)` parameters from `fastapi`:
         ```python
         from fastapi import Form
         def create_license(
             db: SessionDep,
             product_name: str = Form(""),
             purchase_date: str = Form(""),
             expiry_date: str = Form(""),
             responsible: str = Form(""),
             cost: str = Form(""),
             comment: str = Form(""),
         ):
         ```
       - Basic validation: if `product_name` is empty or `expiry_date` is empty or `purchase_date` is empty, re-render form with `errors` dict. Full validation logic will be added in Plan 03.
       - On success: create `License(product_name=product_name, purchase_date=date.fromisoformat(purchase_date), expiry_date=date.fromisoformat(expiry_date), responsible=responsible or None, cost=cost or None, comment=comment or None)`, `db.add()`, `db.commit()`.
       - Return `RedirectResponse(url="/", status_code=303)` per D-03.

    3. `GET /licenses/{license_id}/edit` — renders `license_form.html` in "edit" mode (per D-02, LIC-02).
       - `sync def edit_license(license_id: int, request: Request, db: SessionDep):`
       - Query `db.get(License, license_id)`. If not found, return 404 page (see Plan 02 for full 404 template; for now raise `HTTPException(404)`).
       - Pass context: `{"mode": "edit", "title": "Редактирование лицензии", "action_url": f"/licenses/{license_id}", "submit_text": "Сохранить лицензию", "license": license, "errors": {}}`

    4. `POST /licenses/{license_id}` — updates an existing license.
       - Same form parsing as create. On success, update fields on the existing License object, `db.commit()`, `RedirectResponse(url="/", status_code=303)`.
       - Use POST (not PUT) since HTML forms only support GET/POST. The route path includes the ID to distinguish from create.

    5. `DELETE /licenses/{license_id}` — deletes a license (per D-05, D-06, LIC-03).
       - `sync def delete_license(license_id: int, db: SessionDep):`
       - Query `db.get(License, license_id)`. If not found, return 404.
       - `db.delete(license)`, `db.commit()`.
       - Return `Response(status_code=200, content="", headers={"HX-Trigger": "license-changed"})` — empty body causes HTMX `hx-swap="outerHTML"` on `closest tr` to remove the row. The `HX-Trigger: license-changed` header tells HTMX to fire a custom event that the stats section listens for.

    Register router: `router = APIRouter(tags=["licenses"])`
