1. Create `app/services/scheduler.py`:

   Module-level: `from apscheduler.schedulers.background import BackgroundScheduler` and `from apscheduler.triggers.cron import CronTrigger`. Create module-level `scheduler = BackgroundScheduler()`.

   `def send_daily_digest():` — The scheduled job. CRITICAL: Creates its own session via `from app.database import engine; from sqlalchemy.orm import Session; with Session(engine) as db:` (NOT request-scoped get_session, per Pitfall 1). Inside the session:
   - Read `telegram_bot_token` and `telegram_chat_id` from AppSettings (query by key).
   - Per D-11: `if not token or not chat_id: return` (silently skip).
   - Call `get_global_threshold(db)` to get threshold.
   - Query `db.query(License).all()`.
   - Call `enrich_licenses(licenses, threshold)`.
   - Call `format_digest(enriched)`.
   - Per D-04: if result is None, return.
   - Call `send_telegram_message(token, chat_id, message)`.
   - After successful send, upsert `last_digest_sent` key in AppSettings with `datetime.now().isoformat()` value (discretion item: last-sent timestamp for Settings page display).

   `def init_scheduler(hour: int = 9, minute: int = 0):` — Adds the daily_digest job with `CronTrigger(hour=hour, minute=minute)`, `id="daily_digest"`, `replace_existing=True`, `misfire_grace_time=3600`. Guards against double-start: `if not scheduler.running: scheduler.start()`. Per Pitfall 2.

   `def reschedule_digest(hour: int, minute: int):` — Calls `scheduler.reschedule_job("daily_digest", trigger=CronTrigger(hour=hour, minute=minute))`. Per D-07.

   `def shutdown_scheduler():` — Calls `scheduler.shutdown(wait=False)` if `scheduler.running`.

2. Edit `app/main.py` lifespan:
   - Add imports: `from app.services.scheduler import init_scheduler, shutdown_scheduler` and `from app.models import AppSettings` and `from sqlalchemy.orm import Session` and `from app.database import engine`.
   - After `bootstrap_settings()`, read `notify_time` from AppSettings: `with Session(engine) as db: row = db.query(AppSettings).filter_by(key="notify_time").first(); time_str = row.value if row and row.value else "09:00"`.
   - Parse: `hour, minute = int(time_str.split(":")[0]), int(time_str.split(":")[1])`.
   - Call `init_scheduler(hour=hour, minute=minute)`.
   - After `yield`, call `shutdown_scheduler()`.

3. Edit `app/routers/settings.py` — In the POST `/settings` handler, after saving all settings, add reschedule logic:
   - Import `from app.services.scheduler import reschedule_digest`.
   - After `save_setting(db, "notify_time", notify_time)`, parse the saved time: `h, m = int(notify_time.split(":")[0]), int(notify_time.split(":")[1])`.
   - Call `reschedule_digest(h, m)`. Wrap in try/except to handle case where scheduler is not running (e.g., in tests): `try: reschedule_digest(h, m) except Exception: pass`.
