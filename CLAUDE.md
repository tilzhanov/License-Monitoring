# License Monitoring

Внутренний дашборд АО «Транстелеком»: следит за сроками лицензий и сервисных контрактов, шлёт Telegram-дайджест до истечения.

Текущий статус, активная фаза и следующее действие — в [.planning/STATE.md](.planning/STATE.md); читай его перед задачей на фичу или рефакторинг. Границы фаз и формулировки требований — в [.planning/ROADMAP.md](.planning/ROADMAP.md) и [.planning/REQUIREMENTS.md](.planning/REQUIREMENTS.md). Закончив задачу, которая поменяла поведение или архитектуру, обнови STATE.md.

## Один актив, два имени

ORM-класс — `Asset`: и лицензия, и контракт поддержки, различаются полем `asset_type`. Имя `License` в `app/models.py` — алиас на `Asset`, оставленный ради legacy-путей `/licenses/*` и старых тестов; в новом коде пиши `Asset`. Отображаемое имя у обоих типов лежит в поле `product_name` — у контракта поддержки это название контракта, а не продукта.

## Два пути создания актива

Активы заводятся и правятся двумя независимыми роутерами, у каждого свой валидатор формы:

| Роутер | Пути | Роль |
|---|---|---|
| `app/routers/catalog.py` | `/catalog/*` | канонический: вендор → продукт → актив |
| `app/routers/licenses.py` | `/licenses/*` | legacy: детальная страница, форма правки, удаление |

Добавляя или меняя поле актива, проходи оба пути целиком: правило валидации, шаблон формы, шаблон детальной страницы. Расхождение между ними — главный источник багов здесь: так `purchase_date` оказался обязательным в одной форме и необязательным в другой.

Обязательны только `product_name` и `expiry_date` — остальные поля актива nullable. В шаблонах ставь защиту перед `.strftime()` и `.isoformat()`: пустая дата даёт `UndefinedError: 'None' has no attribute 'strftime'` и роняет всю страницу в 500.

## Конвенции

- **`def`, а не `async def`** для роутов, которые ходят в БД. Сессия SQLAlchemy синхронная; FastAPI уводит `def`-обработчики в threadpool, а `async def` заблокирует event loop на каждом запросе.
- **HTMX-эндпойнты отдают HTML-фрагменты** из `templates/partials/`, не JSON.
- **`Jinja2Templates` — синглтон**: `from app.templates import templates`. Там же зарегистрирован фильтр `money`; отдельный экземпляр в роутере приходит без фильтров и падает на рендере.
- **Строки в Telegram проходят через `html.escape()`** — сообщения уходят с `parse_mode=HTML`, и сырой `&` или `<` в названии продукта ломает отправку.
- **Секреты Telegram живут только в `.env`.** Их сознательно убрали из БД и из UI настроек, а legacy-строки `telegram_*` вычищаются из `app_settings` при старте (`bootstrap_settings` в `app/database.py`). Порог уведомлений — наоборот, настраивается в UI и резолвится как БД → env → дефолт (`get_global_threshold` в `app/services/status.py`).

## Прогон тестов

Локального venv нет, `pytest` живёт в образе. Тесты работают на in-memory SQLite и продовую БД не трогают.

```bash
# против запущенного контейнера — код берётся из образа
docker compose exec web pytest tests/ -q

# из рабочего дерева — этим проверяй свои правки до деплоя
docker build -q -t lm-test . && \
  docker run --rm --entrypoint python -v "$PWD/tests:/app/tests:ro" lm-test -m pytest tests/ -q
```

Код в образ запекается на сборке (том смонтирован только под `/data`), поэтому первая команда покажет состояние деплоя, а не твоих правок.

## Прод

Разворачивается на внутреннем сервере тем же Docker Compose. Адрес, пользователь и рабочая папка — в `credential.txt`, который остаётся вне git. На сервере крутятся и другие сервисы: держи команды внутри папки проекта и не трогай docker глобально.
